# DevOps Learning Roadmap

A practical sequence for a beginner studying consistently. Move forward after completing the exercise and writing down what was learned.

## Phase 1 — Linux and networking
- [ ] Navigate files and directories; use pipes and redirection.
- [ ] Understand users, groups, permissions, and processes.
- [ ] Inspect CPU, memory, disk, IP addresses, DNS, and ports.
- [ ] Read service status and logs with `systemctl` and `journalctl`.
- [ ] Write and debug basic Bash scripts.

## Phase 2 — Git and GitHub
- [ ] Understand working tree, staging area, and commits.
- [ ] Create branches and merge changes.
- [ ] Write clear commit messages.
- [ ] Open a pull request and review a diff.

## Phase 3 — Containers
- [ ] Build and run a Docker image.
- [ ] Publish ports and use bind mounts/volumes.
- [ ] Use environment variables safely.
- [ ] Define a multi-container app with Compose.

## Phase 4 — CI/CD
- [ ] Understand workflow, job, and step.
- [ ] Run automated checks on pull requests.
- [ ] Store secrets in repository/environment secrets, never in source files.
- [ ] Understand artifacts and deployment approvals.

## Phase 5 — Operations
- [ ] Configure Nginx as a web server/reverse proxy.
- [ ] Collect metrics and logs.
- [ ] Define a basic health check and alert threshold.
- [ ] Document backup, recovery, and incident procedures.

## Phase 6 — Cloud and Infrastructure as Code
- [ ] Learn core cloud networking and identity concepts.
- [ ] Provision a small test environment.
- [ ] Learn Terraform fundamentals and state handling.
- [ ] Tear down lab resources to avoid unexpected costs.

## Study routine
Aim for 1–2 focused hours: 20 minutes reading, 50 minutes hands-on practice, and 10 minutes documenting results. Prefer a small verified lab over copying a large configuration without understanding it.
